# Shivani Singh — Personal Portfolio

Welcome to my personal portfolio repository. This website brings my professional profile and work together in one place and provides visitors with an easy way to explore my background and portfolio.

🌐 **Live Portfolio:** [shivanisingh710.github.io/Portfolio](https://shivanisingh710.github.io/Portfolio/)

## About the Project

I created this portfolio with the help of **Google Antigravity** using prompt-based development. I described the design and content requirements in natural language, then used the generated HTML and CSS as the foundation for the website.

The project reflects an AI-assisted approach to building a simple web experience: using prompts to translate ideas into frontend code and publishing the result through GitHub Pages.

## Built With

- **HTML5** — page structure and content
- **CSS3** — styling and visual presentation
- **Google Antigravity** — AI-assisted, prompt-based development
- **GitHub** — source-code repository and version control
- **GitHub Pages** — hosting and deployment

## Run Locally

This is a static website. No Python environment, package installation, or build step is required for a basic local preview.

1. Clone the repository:

   ```bash
   git clone https://github.com/Shivanisingh710/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your web browser.

## Deployment

The website is published using **GitHub Pages**. To update the live portfolio, commit and push the latest website changes to the repository's publishing branch configured in **Settings → Pages**.

## AI-Assisted Development

Google Antigravity was used as an AI development environment. The website was created through prompts that guided the generation and refinement of the HTML and CSS. The source code is maintained in this GitHub repository.
